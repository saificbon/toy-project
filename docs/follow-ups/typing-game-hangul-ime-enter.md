# 한글 조합 중 Enter 제출을 실제 입력기로 확인하지 못함

- 증상: 스펙 수용 기준 4(한글 입력 도중 Enter를 눌러도 마지막 글자까지 반영해 판정)를 실제 한글 입력기로 확인하지 못했습니다. 자동화 브라우저는 조합 입력을 만들 수 없습니다.
- 구현: `keydown`의 Enter에서 `currentTarget.value`로 판정하고 `setInput("")`으로 비웁니다. 일부 브라우저에서는 조합 종료가 마지막 글자를 입력창에 다시 채울 수 있다는 지적이 있습니다.
- 다음 단계: Windows Chrome과 Edge에서 한글을 직접 치며 Enter 직후 입력창이 비는지, 다음 입력 앞에 글자가 남지 않는지 확인합니다. 남으면 `compositionend` 이후에 비우도록 바꿉니다.
