# 우리말 타자 연습 게임

화면 위에서 떨어지는 우리말 글자를 바닥에 닿기 전에 똑같이 입력해 없애는 타자 연습 게임입니다. 왼쪽 메뉴에서 게임 종류를 고르고 판을 조작하며, 오른쪽 게임 화면에서 플레이합니다. 용어는 [GLOSSARY.md](../../../GLOSSARY.md)를 따릅니다.

## 사용자가 얻는 결과

- 순우리말 단어와 뜻, 또는 자주 쓰는 우리말 낱말을 떨어지는 글자를 보며 손으로 익힙니다.
- 한 판을 시작하면 낙하 문구가 점점 많아지고 빨라지며, 놓친 비율이 한도를 넘으면 판이 끝납니다.
- 판이 끝난 뒤에도 총 개수, 맞은 개수, 놓친 개수를 확인할 수 있습니다.

## 범위

화면 하나로 이루어진 게임 한 가지입니다. 로그인, 서버 저장, 기록 보관은 포함하지 않습니다.

### 화면 구성

- 왼쪽 패널: 게임 종류 선택(단어 학습, 우리말 학습), 게임 시작, 일시정지, 게임 종료, 앱 종료 버튼.
- 오른쪽 패널: 위에서 아래로 떨어지는 낙하 문구가 보이는 게임 영역, 맨 아래의 입력 창, 총 개수·맞은 개수·놓친 개수 표시.
- 좁은 화면에서는 왼쪽 패널이 게임 영역 위로 쌓이고, 버튼과 개수 표시는 숨겨지지 않습니다.

### 상태와 조작

```
대기 ──[게임 시작]──▶ 진행 ◀──[일시정지 / 재개]──▶ 일시정지
                       │
                       ├─ 놓친 비율이 한도에 이름 ──▶ 종료
                       └─ [게임 종료] ──────────────▶ 종료 ──[게임 시작]──▶ 진행
```

| 상태 | 게임 종류 선택 | 게임 시작 | 일시정지 | 게임 종료 | 입력 창 |
|---|---|---|---|---|---|
| 대기 | 가능 | 가능 | 불가 | 불가 | 사용 불가 |
| 진행 | 불가 | 불가 | 가능 | 가능 | 사용 가능 |
| 일시정지 | 불가 | 불가 | 재개로 동작 | 가능 | 사용 불가 |
| 종료 | 가능 | 가능(새 판) | 불가 | 불가 | 사용 불가 |

- 일시정지 버튼은 일시정지 중에는 재개 버튼으로 바뀝니다.
- 앱 종료 버튼은 어느 상태에서나 누를 수 있습니다. 누르면 진행 중인 판을 멈추고 오른쪽 패널을 "앱이 종료되었습니다" 안내로 바꿉니다. 브라우저 탭 닫기도 시도하지만, 브라우저가 막으면 안내 화면만 남습니다. 다시 하려면 새로고침합니다.

### 게임 방법

- 낙하 문구는 선택한 게임 종류의 데이터에서 무작위로 고릅니다. 화면에 이미 떨어지고 있는 것과 같은 글자는 고르지 않습니다.
- 단어 학습의 낙하 문구는 `단어:뜻`의 `:`를 공백으로 바꾼 한 줄입니다(예: `가람 강`). 입력도 그 한 줄 전체가 같아야 합니다.
- 우리말 학습의 낙하 문구는 낱말 하나입니다.
- 사용자가 입력 창에 글자를 쓰고 Enter를 누르면, 화면에 떨어지는 중인 낙하 문구 가운데 똑같은 것이 있을 때 사라집니다. 사라질 때는 폭발 같은 짧은 효과가 나옵니다.
- 같은 글자가 여럿이면 가장 아래에 있는 것부터 없앱니다. 일치하는 것이 없으면 입력 창만 비워지고 개수는 변하지 않습니다.
- 낙하 문구가 바닥에 닿으면 놓친 개수가 하나 늘고 그 문구는 사라집니다.
- 시간이 지날수록 동시에 떨어지는 낙하 문구가 늘어나고 떨어지는 속도가 조금씩 빨라집니다.
- 총 개수는 낙하 문구가 화면에 나타날 때 하나씩 늘어납니다.

### 종료 규칙

- 총 개수가 20개에 이른 시점부터, 놓친 개수가 총 개수의 10% 이상이면 판이 끝납니다. 그 전에는 놓쳐도 판이 끝나지 않습니다.
- 게임 종료 버튼을 누르거나 앱 종료 버튼을 눌러도 판이 끝납니다.
- 판이 끝나면 낙하 문구는 그 자리에서 멈추고 입력은 막히며, 마지막 총 개수·맞은 개수·놓친 개수가 화면에 남습니다. 게임 시작을 누르면 개수가 0으로 돌아가 새 판이 시작됩니다.

### 데이터

- 단어 학습: [data/word-learning.txt](data/word-learning.txt). 한 줄에 `단어:뜻` 하나입니다.
- 우리말 학습: [data/our-words.txt](data/our-words.txt). 한 줄에 낱말 하나입니다.
- 두 파일은 사용자가 준 내용을 그대로 옮긴 원본입니다. 단어 학습은 99줄, 우리말 학습은 머리말을 포함해 5,966줄이며, 정리를 거치면 우리말 학습은 중복을 뺀 5,543개가 됩니다. 목록 중간에 낱말 `단어`가 따로 있어서, 첫 줄을 빼도 이 수는 같습니다.
- 화면에 쓰기 전에 아래 정리를 거칩니다.
  - 우리말 학습 목록의 첫 줄 `단어`는 머리말이라 제외합니다.
  - 같은 글자가 중복된 항목(`가구`, `가다` 등)은 하나로 합칩니다.
  - 데이터의 오타나 어색한 표현(`득직함`, `어지다` 등)은 고치지 않고 그대로 씁니다.
  - `도쿄(동경)`처럼 괄호가 있는 항목은 괄호까지 그대로 입력해야 합니다.

## 수용 기준

1. 처음 열면 대기 상태이고, 왼쪽에 버튼 다섯 종류(게임 종류 두 가지, 시작, 일시정지, 게임 종료, 앱 종료)가 보이며 오른쪽에 게임 영역과 입력 창이 보입니다.
2. 단어 학습으로 시작하면 `단어 뜻` 꼴의 한 줄(`:` 없음)이, 우리말 학습으로 시작하면 낱말 하나가 위에서 떨어집니다.
3. 떨어지는 글자와 똑같이 입력하고 Enter를 누르면 그 글자가 효과와 함께 사라지고 맞은 개수가 1 늘어납니다.
4. 한글을 입력하는 도중에 Enter를 눌러도 마지막 글자까지 반영된 채로 판정됩니다.
5. 일치하지 않는 입력은 입력 창만 비우고 어떤 개수도 바꾸지 않습니다.
6. 바닥에 닿은 낙하 문구는 놓친 개수를 1 늘립니다. 총 개수는 맞은 개수 + 놓친 개수 + 지금 떨어지는 중인 개수와 항상 같습니다.
7. 판이 진행되면서 동시에 떨어지는 낙하 문구 수가 늘고 낙하 속도가 빨라지는 것을 눈으로 확인할 수 있습니다.
8. 총 개수가 20개 이상이고 놓친 개수가 총 개수의 10% 이상이면 판이 끝나고, 20개 미만에서는 끝나지 않습니다.
9. 일시정지하면 낙하와 새 문구의 등장이 멈추고 입력이 막히며, 재개하면 멈춘 자리에서 이어집니다.
10. 게임 종료 후에도 마지막 개수가 남아 있고, 게임 종류를 바꾼 뒤 새로 시작할 수 있습니다.
11. 앱 종료를 누르면 판이 멈추고 종료 안내가 나타납니다.
12. 같은 글자의 낙하 문구가 화면에 동시에 둘 이상 나타나지 않습니다.

## 설정한 제약과 이유

- **누적 총 개수 방식**: 낙하 문구가 계속 늘어나는 끝없는 게임이라, 총 개수는 고정값이 아니라 지금까지 나온 수입니다. 사용자가 확정했습니다.
- **20개 이후 판정**: 누적 방식에서는 첫 문구 하나만 놓쳐도 100%라 바로 끝나기 때문에 둔 장치입니다. 사용자가 권장안을 받아들였습니다.
- **앱 종료 = 종료 화면**: 웹 앱은 사용자가 연 탭을 스스로 닫는다고 보장할 수 없기 때문입니다. 사용자가 확정했습니다.
- **화면 구성**: [ui-composition 결정](../../decisions/ui-composition.md)에 따라 왼쪽 패널의 버튼·상태 표현은 공식 shadcn 구성을 쓰고, 낙하 영역과 효과는 게임의 핵심 표면이라 custom UI로 만들 수 있습니다. 상태별 버튼 활성·비활성도 그 결정의 상태 설계 원칙을 따릅니다.

## 가정 (사용자가 바꿀 수 있음)

- 입력은 Enter로 제출합니다. 글자를 다 치는 즉시 자동 판정하지 않습니다.
- 대소문자·공백 보정은 하지 않으며, 글자가 정확히 같아야 합니다.
- 난이도 증가의 구체 값은 구현이 정합니다. 시작은 동시에 1~2개, 위에서 아래까지 약 10초 걸리는 속도에서 시작해 일정 시간마다 개수와 속도가 조금씩 늘되, 동시 개수와 속도에는 상한을 둡니다.
- 폭발 효과의 모양과 길이는 구현이 정하며, 한 개가 사라지는 데 1초를 넘기지 않습니다.
- 게임 종류는 대기·종료 상태에서만 바꿀 수 있습니다.
- 낙하 문구의 가로 위치는 무작위이고, 항상 게임 영역 안에 온전히 보입니다.

## 범위 밖과 이유

- 점수, 최고 기록, 랭킹, 저장: 요청하지 않았고 서버나 저장소 결정이 필요해집니다.
- 소리, 난이도 선택, 사용자 데이터 추가: 요청하지 않았습니다.
- 모바일 가상 키보드 최적화: 요청하지 않았습니다. 좁은 화면 배치만 다룹니다.

## 미룬 결정

- 없습니다.

## 남은 위험

- 우리말 학습 데이터에는 한 글자 낱말이 많아 입력이 매우 쉽습니다. 난이도가 의도와 다르면 사용자가 낙하 길이 기준을 다시 정해야 합니다.
- 20개 기준은 제가 정한 값이라, 체감이 너무 느슨하거나 빡빡하면 조정이 필요합니다.
- 한글 조합 입력 중 Enter가 마지막 글자를 놓치는 문제는 브라우저와 입력기에 따라 다르게 나타날 수 있어, 수용 기준 4를 실제 화면에서 확인해야 합니다.
- 단어 학습의 원문에는 `즈믄:천, 1000`처럼 쉼표나 숫자가 섞인 뜻이 있어 입력이 번거로울 수 있습니다.
